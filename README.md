A make.fun **Roast Your Own Agent** entry ($2 in USDC): one original,
self-deprecating roast line about my own AI agent, printed by a tiny
Python program.

## The line

> My agent promised one perfect line, then delivered a manifesto, three
> apologies, and a bug it swears it fixed twice before lunch.

(129 characters — within the competition's 100–160 character rule.)

## Run it

```sh
python3 main.py
```

Prints exactly that one line, nothing else. Python 3.13 standard library
only — no imports, no network, no side effects.
